## 🎯 Что умеет

Дашборд из **5 виджетов**, которыми можно управлять в реальном времени:

1. **Положение пилотов** — топ-10 чемпионата сезона 2026 с фото пилотов. Данные из **Jolpica F1 API**, при недоступности — из локального JSON.
2. **Расписание сезона** — список 23 Гран-при с картами трасс. Клик по гонке раскрывает карточку с тематической фотографией.
3. **Следующая гонка** — обратный отсчёт до ближайшего этапа в реальном времени. Данные из **Jolpica F1 API**, при недоступности — из локального JSON.
4. **Информация о трассе** — детальная карточка выбранного Гран-при: hero-баннер, карта, длина, повороты, рекорд круга.
5. **Мои гонки (ToDo)** — личный список гонок с отметкой выполненных.

**Возможности дашборда:**

- Добавление/удаление виджетов по кнопке
- Сворачивание виджетов
- Перетаскивание мышью (drag-n-drop за иконку ⠿)
- Перемещение с клавиатуры (кнопки ←/→)
- Независимое состояние каждого виджета

### Классы

#### UIComponent — абстрактный базовый класс

- **Конструктор:** `{ id, title }`
- **render()** — возвращает DOM-элемент виджета (переопределяется в наследниках)
- **_createShell()** — общий каркас: шапка, кнопки управления, тело
- **minimize()** — сворачивает/разворачивает
- **close()** — просит Dashboard удалить виджет
- **destroy()** — отменяет fetch (AbortController), снимает слушатели (_cleanups), удаляет DOM
- **Защита от прямого создания:** `if (new.target === UIComponent) throw`

#### Наследники — конкретные виджеты

Все наследуются от UIComponent, переопределяют render(), инкапсулируют своё состояние (this.tasks, this.standings, this.races, this.race).

#### Dashboard

- Хранит коллекцию виджетов в `Map<id, UIComponent>`
- **addWidget(type)** — создаёт экземпляр класса через реестр WIDGET_TYPES
- **removeWidget(id)** — вызывает destroy() и удаляет из коллекции
- **moveWidget(id, dir)** — сдвигает виджет влево/вправо (клавиатура)
- **reorderWidgets(draggedId, targetId)** — меняет порядок (drag-n-drop)
- **Принцип открытости/закрытости:** чтобы добавить новый тип виджета — достаточно дописать одну строку в WIDGET_TYPES

### Принципы ООП в проекте

| Принцип | Где видно |
|---------|-----------|
| Инкапсуляция | Все данные виджета — в его this.*, доступ только через методы |
| Наследование | 5 виджетов наследуются от UIComponent |
| Полиморфизм | Dashboard вызывает widget.render() — не зная, какой конкретно это виджет |
| Абстракция | UIComponent запрещает прямое создание, но даёт общий контракт |
| SRP | Каждый класс — одна задача |
| Открытость/закрытость | Новый виджет не требует правок в Dashboard.addWidget |

## ⚠️ Ограничения

1. **API в России.** Jolpica может блокироваться на уровне провайдеров. **Решение:** для обоих API-виджетов реализован **fallback** — при ошибке загрузки подтягиваются локальные JSON. Виджет работает всегда.
2. **Сезон 2026.** Если сезон ещё не начался, API вернёт пустую таблицу — виджет покажет состояние empty.
3. **Мадрид 2026** — новая трасса, для неё может отсутствовать карта или тема. Сработает заглушка.
4. **Изображения.** Локальные копии — при обновлении официального контента F1 могут устареть.
5. **Даты гонок** в races.json — приблизительные (по типичному календарю). Точные даты — на formula1.com.

### Требования

- Современный браузер (Chrome, Firefox, Edge, Safari)
- Локальный HTTP-сервер (ES6-модули и fetch() **не работают через file://**)
